# Maryland Eagles Eyes

The welcome page for **122eagles.com**, focused on Maryland, USA.

Static HTML and CSS with an original Chesapeake Bay SVG illustration. No
JavaScript, framework, tracking or third-party runtime requests. Visual direction
inspired by The Bridge's muted landscape, serif typography and open composition;
its code, branding and illustrations are not reused.

Preview with `python3 -m http.server 8012`. Vercel framework preset: Other.
Production branch: `main`. Root directory: repository root. No build command.

Fonts: Lora and Instrument Sans, distributed under the SIL Open Font License;
see `assets/OFL-*.txt`. Font files are self-hosted.
